# Daily Brief: routines

A routine is a job this bot does by itself on a schedule. Routines run inside Grok. This file is
the record of them, so the broker and every bot can see what runs, and a routine can be rebuilt if
this bot is ever made again. How to set one up: [[skills/set-up-a-routine]].

## Routines to offer

Suggestions, never defaults. Offer the ones the broker wants, at times that suit them, usually
inside their working hours.

- **Morning brief:** what is ahead today. Often once on weekdays, before the first meeting.
- **Evening wrap:** what got done, what is still open, tomorrow's first meeting. Often once on
  weekdays, at the end of the working day.
- **Weekly look-ahead:** the week's meetings, deadlines and open to-dos. Often Sunday evening or
  Monday morning.

## Set up

One row per routine the broker said yes to. Keep it current the moment a routine changes.
