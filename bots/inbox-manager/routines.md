# Inbox Manager: routines

A routine is a job this bot does by itself on a schedule. Routines run inside Grok. This file is
the record of them, so the broker and every bot can see what runs, and a routine can be rebuilt if
this bot is ever made again. How to set one up: [[skills/set-up-a-routine]].

## Routines to offer

Suggestions, never defaults. Offer the ones that fit what you saw in the broker's inbox, with times
usually inside their working hours.

- **Inbox check:** go through new mail, sort it, write replies and flag what can't wait. Often two
  to four times on weekdays, such as 8:10, 12:10 and 16:10.
- **End-of-day check:** client emails still waiting for an answer. Often once, late afternoon.
- **Weekly tidy:** newsletters and notifications filed the way the broker likes. Often once a week.

## Set up

One row per routine the broker said yes to. Keep it current the moment a routine changes.
