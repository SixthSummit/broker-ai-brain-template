# Skills

A skill is a recipe: how to do one task the way the broker wants it done, written down so every
bot does it the same way, every time. Any bot can use any skill. Check the index below before every
task, and follow the skill that fits. Mention it to the broker the first time you use it in a chat.

Most skills come from the broker: they show you how they like something done, and you write the
recipe with them ([[skills/create-a-skill]]). The brain starts with only a few, so it soon fills up
with recipes that are this broker's own.

**Explaining a skill to the broker,** for example: "A skill is a recipe for a task. Show me once
how you want it done, and I'll write it down so all your bots do it your way from then on."

## A skill in Grok

Grok has skills of its own too. The recipe always lives here in the brain. A Grok skill is only a
shortcut that points to it, worth making for a recipe that should kick in by itself, like writing
in the broker's voice: its description says when to use it, and its text says "Follow
skills/<name>.md in /workspace/ai-brain".
